ESP LAB 1 RGB LED

Collaboration between Jihu Nam and Jan-Patrick Glaeser: 

Task A
    We changed by using neopixelWrite() the RGB values to Green, Blue and White. We observed that we can change the intensity of the colours with the values of neopixelWrite.

 Task B
    The original program didn't change the colours as fast as the new pattern with the smaller delays.

Task C
    Now we created the sequence. Red, Green, Blue, Off.
    Each of the colourstates lasts 500ms and it's continuing in a loop the whole time.

Task D
    We created a custom LED colour pattern with different brightness values, which also have different delays. This loop continues as well the whole time without stopping.
